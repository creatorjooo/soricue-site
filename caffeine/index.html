시작·일시정지·종료

메뉴바에서 메인 창을 열고 세션 탭에서 옵션과 시간을 고른 뒤 시작하세요. 일시정지는 실제 잠자기 방지를 해제하고, 재개는 선택한 옵션으로 이어갑니다. 시간이 끝나거나 중지를 누르면 세션이 종료되며 앱은 계속 열려 있습니다. 창을 닫아도 메뉴바 앱은 유지됩니다.

작업에 맞는 옵션

발표·강의에는 화면 유지 프리셋을, 다운로드·렌더링에는 화면 절전을 허용하면서 Mac의 자동 잠자기를 막는 프리셋을 사용할 수 있습니다. 다운로드나 렌더링 완료를 감지하는 기능은 아닙니다. 보안 잠금, 사용자가 직접 내린 잠자기 명령, 덮개 닫힘 및 전원 부족 상황은 macOS가 제어합니다.

자동화가 다시 시작되지 않는 경우

추가한 자동화 규칙은 직접 켜야 작동합니다. 선택한 조건은 모두 충족해야 하며 높은 우선순위가 먼저 적용됩니다. 직접 중지하면 같은 조건이 유지되는 동안 자동으로 다시 시작하지 않습니다. 조건이 끝났다 다시 충족되거나 재허용을 선택하면 자동화를 다시 사용할 수 있습니다.

App Store 버전과 Direct 버전

Caffeine Session은 Mac의 자동 잠자기 방지, 프리셋과 자동화, 로컬 3D 도식을 제공합니다. 실제 온도·팬 RPM·팬 제어·덮개 닫힘 제어·감마 밝기 조절은 App Store 버전에 포함되지 않습니다. Direct 버전의 센서·팬·외장 밝기 기능은 기기와 권한에 따라 제공됩니다.
