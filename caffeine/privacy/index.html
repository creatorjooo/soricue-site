적용 범위와 운영자

이 정책은 joo minjae가 제공하는 Caffeine 및 Mac App Store용 Caffeine Session에 적용됩니다. SoriCue 음성 앱의 정책과는 별개입니다. Caffeine 앱의 정보 처리, 이 웹사이트 방문 및 이메일 지원 문의를 아래에서 구분하여 설명합니다.

앱의 정보는 Mac 안에서 처리합니다

Caffeine은 계정 가입, 광고, 추적·분석 SDK, 자동 서버 업로드를 사용하지 않습니다. 세션 옵션, 프리셋, 사용자가 지정한 앱 식별자와 자동화 규칙, 단축키, 언어 선택은 Mac의 로컬 설정에 저장됩니다. 앱은 이러한 정보를 개발자 서버로 전송하지 않습니다.

로컬 시스템 정보

잠자기 방지와 자동화를 위해 전원·배터리·디스플레이·앱 실행 상태 및 macOS 열 상태를 사용합니다. 자동화는 앱의 실행 여부를 확인하며 녹음, 다운로드, 렌더링의 내용이나 완료를 분석하지 않습니다. App Store 버전은 실제 온도·팬 RPM을 읽거나 팬을 제어하지 않습니다. Direct 버전은 지원되는 센서와 팬을 로컬에서 읽으며 별도 권한을 승인한 경우 팬을 제어합니다. 외장 밝기의 화면 식별 정보도 Mac 안에 보관하고 지원 진단에 포함하지 않습니다.

선택적 이력과 직접 저장하는 진단

세션 이력은 기본적으로 꺼져 있습니다. 사용자가 켜면 세션 상태·일시·자동 실행 여부를 최대 100개까지 로컬에 보관하며 직접 삭제하거나 내보낼 수 있습니다. 지원 진단은 사용자가 파일 저장을 선택했을 때만 생성됩니다. 진단에는 앱·빌드·세션 상태·오류 종류 등이 포함되며 계정, 기기 시리얼, 개인 파일 경로, 실행 앱 목록은 제외합니다. 파일은 자동 전송되지 않습니다.

사용자가 선택하는 기능과 권한

자동화 규칙, 로그인 시 실행, 전역 단축키는 사용자가 켠 경우에 동작합니다. Direct의 고온 알림을 직접 켤 때 알림 권한을 요청합니다. 앱 종료는 진행 중인 세션의 잠자기 방지를 해제합니다. 로컬 3D 화면은 앱에 포함된 파일을 사용하며 광고·추적·원격 콘텐츠를 불러오지 않습니다.

이메일 지원 문의

사용자가 지원 이메일로 직접 보내는 이메일 주소, 문의 내용 및 선택한 첨부 파일은 문의 응대와 문제 해결에 사용합니다. 민감한 정보가 들어 있는 첨부 파일은 보내기 전에 확인해 주세요. 문의 처리에 필요한 기간 보관하며, 처리가 끝나 불필요해진 정보는 삭제합니다. 법령에 따른 보존 의무가 있는 정보는 해당 기간 보관할 수 있습니다. 문의 정보의 확인·정정·삭제 요청도 같은 연락처로 보낼 수 있습니다.

웹사이트와 메일 서비스

이 지원 웹사이트는 GitHub Pages에서 제공됩니다. 웹사이트 방문에 따른 IP 주소 등의 서비스 운영 정보는 GitHub의 정책에 따라 처리될 수 있습니다. 지원 이메일은 Google Gmail을 이용하므로 이메일과 첨부 파일은 Google의 메일 서비스에서 처리됩니다. Caffeine 앱의 로컬 설정·이력을 이 웹사이트나 메일 서비스로 자동 전송하지 않습니다.
